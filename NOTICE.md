# Attribution

Douyin Thread Ripper is an inspired extension of **Bilibili-thread-ripper** for Douyin.

Original project: https://github.com/MrTangLuyao/Bilibili-thread-ripper

Original author: MrTangLuyao, with Bilibili-thread-ripper contributors.

The original project's concurrent HTTP byte-range playback acceleration, validation and fallback approach inspired this project. The upstream README, range-core.js, and userscript metadata were reviewed during initial implementation. The implementation here is independent; it is not an official release from the upstream author and does not imply endorsement.
